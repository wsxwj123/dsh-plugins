# BRIEF — 回合刻度显示所有回合

## 现状

DSH 会话历史是分页加载的：旧消息被隐藏，滚动到顶部需点击「加载更早」才追加进 DOM。当前 `dsh-turn-scrubber` 只显示**已加载进客户端快照**（`snapshot.chat.locations.turns`）的回合，隐藏的旧回合没有刻度。

## 本次目标

回合刻度显示**所有回合**（包括未加载进 DOM 的历史回合），让用户在长会话里能一眼看到全部回合、点击定位到任意回合（含需要先加载的旧回合）。

## 成功标准

1. 刻度数 = 会话全部回合数（含未加载部分），不随「加载更早」变化而跳变
2. 点击未加载回合的刻度：能到达该回合（加载策略由方案定）
3. 不破坏现有交互（悬停波形、tooltip、已加载回合的平滑跳转）
4. 性能：长会话（数百回合）下滚动/悬停不卡

## 已确认（2026-08-14 拷问）

1. **未加载回合点击** → 自动连续加载更早历史直到该回合出现 → 平滑滚动定位（加载多页可能等几秒）
2. **压缩回合** → 显示为灰色占位刻度，点击滚到「加载更早」区域附近（跳不到原文）
3. **超长会话** → 刻度间距压到极限仍全显全部回合（不隐藏）

## 敏感面声明

- 读会话历史属正常功能范围（用户自己的会话数据），不涉及其他用户数据
- 不引入新的外部网络请求；数据只在 host↔client 本机范围内流动
- 不记录、不输出任何会话内容到日志
